# Knits - Knitwear Exporter Production Tracking & Delay Warning SaaS

Built for Tiruppur garment export manufacturers with live floor updates, predictive run-rate delay warnings, AI Tamil issue translation, and multi-tenant buyer visibility.

## Live Structure
- `knits-app/`: Full production-grade React + TypeScript + Tailwind application.
- `TDD.md`: Technical Design Document covering architecture, data models, AI pipeline, security, and edge cases.
- `deployment.md`: Step-by-step local setup, demo roles, and environment specifications.
